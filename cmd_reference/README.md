# 内部部署命令参考

[配置矩阵](INDEX.md) · [入库规则与 NOTES 模板](CONTRIBUTING.md)

本目录独立于 skills、tests 和执行器，仅供内部检索、命令规整和配置审阅使用。它不是 Skill 安装包的一部分，不会自动执行或自动加载其中脚本。

按 `模型/部署方案/配置/` 管理，同一方案可有多个配置。以用户提供的脚本为输入；社区规范用于检查，官方示例不自动替代用户命令。

每套配置的 NOTES.md 是说明入口；NOTES.txt 为原始历史记录。catalog.json 是检索索引，不是执行 job_spec。实际部署前须重新绑定 IP、端口、网卡、权重、挂载与工作目录，并核验对应镜像版本。

目录包含内部现场信息和历史路径，不应直接对外发布。第三方代理和扩展保留原有许可证。本次仅纳入本地 Git，未向远端推送。

原始目录 D:/cmd_reference 保留。本次不纳入运行产物 _ascend_runs、停用源码 _retired、停用补丁 upstream/enable-pr18549.sh、缓存及压缩包；这些材料仍在原位置。历史文字提及这些路径，不代表仓库中包含它们。
